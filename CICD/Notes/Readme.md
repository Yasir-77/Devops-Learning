# CI/CD Module

## Understanding CI/CD

### What is CI/CD?

CI/CD is a practice that helps teams build, test, and release code faster and more reliably.

### Continuous Integration (CI)
- Merge code changes frequently  
- Run automated tests on each change  
- Catch bugs early  

### Continuous Delivery (CD)
- Code is always ready to be deployed  
- Deployment is manual but reliable  

### Continuous Deployment (CD)
- Every tested change is automatically deployed  
- No manual intervention required  

### Why CI/CD?
- Faster development  
- Early bug detection  
- Reliable releases
